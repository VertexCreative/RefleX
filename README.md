## 📂 Overview
**RefleX** is a professional aim and reaction trainer. It measures the milliseconds between a target appearing and your click, ranking you based on eSports standards.

## ✨ Key Features
* **Dynamic Spawning:** Targets appear at random coordinates within safe bounds.
* **Ranking System:** Classifies users from "Rookie" to "Machine God".
* **Millisecond Precision:** High-accuracy timing engine.
* **Visual Feedback:** Targets pop and glow upon interaction.

## 💻 Tech Stack
* **Core:** JavaScript DOM Manipulation
* **Animation:** CSS Transitions
* **UI:** Tailwind CSS
